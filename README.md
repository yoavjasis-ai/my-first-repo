# my-first-repo

A practice repository for learning how GitHub pull requests work.

## Getting started

To get a copy of this repository on your computer:

```bash
git clone https://github.com/yoavjasis-ai/my-first-repo.git
cd my-first-repo
```

## How changes are made

1. Create a new branch for your change.
2. Commit your edits on that branch.
3. Open a pull request so the change can be reviewed before it is merged into `main`.
